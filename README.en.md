# Todo4Agent

[简体中文](README.md) | English

## Introduction

> [!TIP]
> For more information about the app, see the website: <https://todo4agent.github.io/en/>

An MCP task list designed for agents: agents can manage your tasks directly through MCP, and you can also maintain them manually in the UI.

The interface supports Simplified Chinese and English; the desktop app is available on Windows, macOS and Linux, with a browser WebUI included.

## Download

Head to [Releases](https://github.com/Todo4Agent/Todo4Agent/releases/latest) to get the installer for your platform.
